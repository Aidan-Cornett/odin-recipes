# My Recipes
This is my first repo project for The Odin Project. It goes over a basic usage of HTML5.

### What is it?
This HTML site has links to 3 sub-pages for recipes. Though I did stretch the definition of what a recipe is for comedic effect. Hopefully I get points for creativity.
Each sub page is it's own recipe with an image and tab title. This should show a use of most of the basic HTML elements.

### Was it fun?
Coming up with the bits was, though HTML gets a little repetitve after a while (I'm sure that's the idea).
